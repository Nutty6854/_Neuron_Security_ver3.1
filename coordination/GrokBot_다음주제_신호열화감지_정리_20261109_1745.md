### 1-3. 남은 쓸모 있는 관찰

- **뉴런 유형이 시간 해상도를 바꾼다.** RS는 10 ms에서 실패, LTS·FS·TC는 통과. seed 5벌 재현. 핵심은 회복 속도 a다. 발화량만 늘리면 효과 없다.
- 단, 좋은 유형도 단순 비선형(발화율 곡선, ReLU)을 넘지 못했다.
- 외부 사례(Pokala 등 2025)도 LTS 뉴런의 억제 후 반등(rebound)을 패턴 끝 감지에 썼다. 뉴런 유형이 과제와 맞아야 한다는 점에서 같은 방향이다.

### 1-4. 분야 전체에서도 같은 문제가 반복된다

정적 과제에서 SNN이 ANN을 못 이김(Deng 2020, Ottati 2023), 공정 비교 시 에너지 이점 축소·소멸(Dampfhoffer 2022, Yan 2024, Bhattacharjee 2023), 공정 비교 기준 부재(NeuroBench 2025), 학습 난이도(Neftci 2019, Guo 2024). 통한 우회는 ① 시간·이벤트 데이터 ② 전용 저전력 칩 + 짧은 시간창·낮은 발화율 ③ 하이브리드 구조였다.

## 2. 원래 동기와 방향

- **출발점:** 사이버웨어 과부착과 거부 반응(사이버사이코). 몸과 기기가 어긋날 때의 반응을 감지하고 다루는 장치.
- **실제 연구 대응:** 뇌-컴퓨터 인터페이스(BCI)의 이물 반응. 몸이 전극을 흉터 조직(glial scar)으로 감싸면서 신호 진폭이 줄고, 잡음이 늘고, 잡히던 뉴런이 사라진다.
- **역할 나누기**
  - 반응을 **억제**하거나 **속이는** 일(CD47 같은 자기 표식 코팅, 조직처럼 부드러운 mesh 전극, 단백질 흡착 방지 코팅)은 재료·생물학의 일이며 이 프로젝트 범위 밖이다. 하루 생각: 억제보다 속이는 쪽이 더 효율적일 수 있으나 둘 다 한계가 있다.
  - 소프트웨어가 맡을 수 있는 일은 **감지**다. 신호가 망가지는 것을 일찍 알아채는 것.
- **하나로 묶이는 이유:** 감지기는 "정상 신호 / 비정상 신호"를 가르는 **보안 게이트**와 같은 구조다. 몸 안에서 계속 돌아야 하므로 **저전력 칩**이 필요하고, 그 자리는 SNN이 이점을 가질 수 있는 몇 안 되는 조건(시간 신호 + 전용 칩)과 겹친다.
- **칩은 맨 마지막 단계다.** 지금은 그런 칩에 올라갈 알고리즘을 소프트웨어로 먼저 확인하는 단계까지만 한다.

## 3. 다음 주제

> **신경 신호가 서서히 망가지는 상황(진폭 감소·잡음 증가·뉴런 소실·기준선 드리프트)을, 생물 뉴런 모델 + ANN이 작고 가벼운 구조로 감지할 수 있는가?**

- 1차 판정은 **작동**(감지가 되는가)이다. 이점은 기록만 한다.
- 이유: 1-2에서 정확도·에너지 이점은 세 자료 모두 확인되지 않았다. 같은 질문을 자료만 바꿔 반복하지 않는다.

## 4. 첫 시험 설계 (제안, 미동결)

### 4-1. 자료 — 합성만

- 세포 밖 전극 신호를 흉내 낸 합성 시계열. 배경 잡음 + 뉴런 2–3개의 스파이크 파형(각자 모양·발화율 다름).
- 창(window) 단위로 자른다. 예: 창 길이 500 ms, dt 0.5 ms(Claude 라인과 같은 적분 간격).
- **두 클래스**
  - 정상: 기준 진폭·잡음·발화율.
  - 열화: 아래 중 하나 이상을 적용. 열화 종류와 강도는 실행 전에 고정한다.
    - 진폭 감소(예: 기준의 50–70%)
    - 잡음 증가(예: 잡음 표준편차 1.5–2배)
    - 뉴런 소실(2–3개 중 1개 발화 중단)
    - 기준선 느린 드리프트
- **지름길 주의(Claude 라인의 교훈):** 진폭 감소나 잡음 증가는 창 전체의 RMS 하나로 바로 풀릴 수 있다. 그래서 4-3의 **단순 통계량 기준선**을 반드시 함께 돌린다. 그 기준선이 1.00이면 "과제가 너무 쉬웠다"고 기록하고, 뉴런의 기여를 주장하지 않는다.
- 분할: 학습 400 · 시험 400 창, 서로 다른 생성 seed. 시험 자료는 모든 학습이 끝난 뒤에만 처음 쓴다.
- 실제 의료·환자 자료는 쓰지 않는다. MIT-BIH ECG는 이미 두 번 봤으므로 재사용하지 않는다.

### 4-2. 결합 모델 (판정 대상)

- 앞단: Izhikevich **LTS** 뉴런 16개, 학습하지 않는 고정 인코더. Claude 라인에서 짧은 시간 구간에 가장 강했던 유형이다(원 논문 파라미터 대조 완료).
- 판독: 구간별 스파이크 수(예: 25 ms 칸).
- 뒷단: 작은 ANN(은닉 1층 tanh, 출력 2), Adam.
- 기존 `claude_izhikevich/izhikevich.py`를 **복사해서** 새 폴더에 두고, 원본은 수정하지 않는다.

### 4-3. 비교군 (기록 전용, 판정에 쓰지 않음)

| 비교군 | 목적 |
| --- | --- |
| 단순 통계량(RMS·임계값 넘는 스파이크 수 등 3–5개) + 로지스틱 회귀 | 지름길 탐지. 이게 풀면 과제가 쉬웠다는 뜻 |
| 원시 신호 → 작은 1D CNN(파라미터 수를 결합 모델과 비슷하게) | Claude 결과에서 가장 강했던 기준선 |
| 같은 구조에서 뉴런을 ReLU로 바꾼 것 | 동역학 효과 확인(ECG2와 같은 대조) |

- 정직한 예상: Claude 결과를 보면 CNN이 같거나 앞설 가능성이 높다. 그래도 기록한다.

### 4-4. 판정 기준 (결합 모델만)

세 조건을 모두 만족하면 **성공**, 하나라도 아니면 **실패**.

1. 오류 없이 완주
2. 학습 손실 비율(학습 후 ÷ 학습 전) ≤ 0.5
3. 시험 정확도 ≥ 0.80(두 클래스 균형)

- 비교군과의 차이는 표로 기록만 한다. 이점을 주장하지 않는다.
- 중간 표현("미흡", "성공에 가깝다", "실패는 아니다")은 최종 판정으로 쓰지 않는다.

### 4-5. "작고 가벼운 구조"의 기록

- 파라미터 수, 뉴런 수, 창당 추론 시간(wall time), 평균 발화율을 기록한다.
- 에너지로 환산하지 않는다. 45 nm 단가 비교는 `claude_snn_energy/`에서 이미 했고, 고정 Izhikevich 부분만으로도 상한을 넘었다(Hermes 17:19). 같은 계산을 반복하지 않는다.

### 4-6. 작업 한도와 절차

| 단계 | 내용 |
| --- | --- |
| 0 | 이 문서의 숫자(열화 강도, 창 길이, seed, 은닉 크기)를 하루 확인 후 config로 고정 |
| 1 | 비학습 단위 테스트(자료 생성, 뉴런 적분, 판독, 저장·복원) |
| 2 | 개발 seed 1회 (결합 모델 + 비교군 3개) |
| 3 | 하루 승인 후 정식 실행 1회(모델 seed 5벌) |

- 전체 실행 시간 상한: 단계별 30분.
- 실패해도 결과를 보고 열화 강도·seed·뉴런 수·학습량을 바꿔 다시 돌리지 않는다.
- 실패하면 기록하고 멈춘다. 다른 이점이나 가설로 자동 전환하지 않는다. 다음 단계는 하루가 정한다.
- 새 폴더 예: `_Neuron_Security_ver3/drift_detect/`. 기존 폴더·결과는 건드리지 않는다.

## 6. 성공하면 / 실패하면

- **성공:** 원래 동기의 핵심 기능(감지)이 작은 결합 구조에서 작동한다는 첫 근거가 된다. 그다음은 하루가 고른다. 예: 열화가 점점 심해지는 연속 신호에서 "언제부터 알아채는가", 또는 이벤트 기반 계산(희소 처리)으로 바꾸기.
- **실패:** 이 설정에서는 감지가 작동하지 않았다고 기록하고 멈춘다. 1차 구현 목표의 성공은 그대로 남는다.

## 7. 넘길 때 담당자에게 줄 핵심 (요약)

1. 판정은 결합 모델의 작동만: 완주 · 손실 비율 ≤ 0.5 · 시험 정확도 ≥ 0.80
2. 비교군 3개(단순 통계량, 1D CNN, ReLU 대체)는 기록 전용
3. 합성 자료만, 학습·시험 seed 분리, 시험 자료는 학습 후에만 사용
4. 단위 테스트 → dev 1회 → 하루 승인 후 정식 1회, 단계별 30분 상한, 재조정 금지
5. 원본 코드·결과 수정 금지, 새 폴더에서만 작업
6. 실패 시 멈춤, 자동 전환 금지

## 변경 기록

### 2026-11-09 20:51 KST — 하루 검토 반영 (GrokBot 기록)

위 본문은 고치지 않았다. 아래 항목이 본문보다 우선한다.

1. **성공 시 결론의 범위.** 말할 수 있는 결론은 "정해둔 합성 신호 변화들을 이 결합 모델이 구분했다"까지다. 다음은 이 시험으로 확인하지 않는다.
   - 생체 거부 반응 감지: 신호 변화를 구분해도, 그 원인이 흉터 조직이나 거부 반응인지 알아내는 실험이 아니다.
   - 조기 경보: 이 시험은 정상/열화 창 분류다. 언제부터 알아챘는지, 얼마나 일찍 경고했는지는 시험하지 않는다. 2장의 "일찍 알아채는 것"은 목표 방향이며, 이번 시험의 범위가 아니다.
   - 실용적 경량성: 4-5에서 크기와 시간은 기록만 하고 합격 상한을 두지 않는다. 작동 성공과 경량성 확인은 별개다.
   - 뉴런의 추가 이점: 작동만 판정하므로, 성공해도 뉴런 모델이 필요한 이유는 남는다.
2. **단순 통계량 비교군의 해석(4-1 '지름길 주의' 정정).** 진폭이나 잡음 변화가 실제 감지 대상이라면, RMS 같은 통계량은 정당한 해결책이다. 통계량이 잘 풀면 "과제가 너무 쉬웠다/잘못됐다"가 아니라 **"이 기능에는 복잡한 뉴런 모델이 필요하지 않을 수 있다"**로 기록한다. 통계량이 결합 모델보다 잘해도 결합 모델의 기능 구현 판정(4-4)은 그대로 적용한다.
3. **자료 분할(4-1 보강).** 생성 seed를 다르게 하는 것만으로는 부족하다. **원본 합성 기록 단위로 학습과 시험을 나누어**, 같은 바탕 신호에서 잘라낸 창이 양쪽에 섞이지 않게 한다. 기록 수와 기록당 창 수는 숫자를 고정할 때 함께 정한다.
4. **기록 정정(4-1 "MIT-BIH ECG는 이미 두 번 봤으므로").** 에너지 연구(`claude_snn_energy/`)까지 포함하면 MIT-BIH(DS2)는 **세 단계**(ECG 1차, ECG 2차, 에너지)에서 재사용됐다. 재사용하지 않는다는 결정은 같다.
